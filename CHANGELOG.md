# Changelog

All notable changes to the ComplyEasyAI plugin are recorded here. The plugin's version is the
`version` in `plugins/complyeasyai/.claude-plugin/plugin.json`.

## 0.1.0 (unreleased)

First version.

- Remote MCP server `complyeasyai` at `https://mcp.complyeasyai.com/mcp`, signed in with OAuth.
- Skills: `readiness`, `risk-review`, `vendor-review`, `questionnaire`, `auditor-requests`,
  `control-evidence` and the guidance skill `complyeasyai-guide`.
- Agent: `audit-prep`.
- No hooks, scripts, executables or local servers.
